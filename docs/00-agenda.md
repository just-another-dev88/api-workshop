# 📅 Workshop Agenda (2 Hours)

## DevSecOps, API Security & Cloud Integration

Squeezed 2-hour high-impact workshop breakdown:

| Time | Duration | Module | Key Takeaway | Format |
|---|---|---|---|---|
| **0:00 – 0:15** | 15 min | **Intro + Ice Breaker** | "What breaks when apps can't talk?" + workshop roadmap | Interactive kickoff |
| **0:15 – 0:45** | 30 min | [M1 – DevSecOps](modules/01-devsecops.md) | Shift Left: automating SAST, SCA, and secret scanning into the CI pipeline | Discussion + GitHub Actions walkthrough |
| **0:45 – 1:30** | 45 min | [M2 – API Security](modules/02-api-security.md) | OWASP Top 10, BOLA, mass assignment, constant-time auth, and rate limits | Live attack & defense demos |
| **1:30 – 2:15** | 45 min | [M3 – Cloud Integration](modules/03-cloud-integration.md) | Modern Cloud Native: API Gateways, IAM, Secrets Manager, and Containers | Architecture walkthrough + checklist |
