# 📅 Workshop Agenda (3 hours)

## DevSecOps, API Security & Cloud Integration

| Time | Module | Key Takeaway | Format |
|---|---|---|---|
| 0:00 – 0:15 | **Welcome & Icebreaker** | "What breaks when apps can't talk?" + workshop goals | Interactive kick-off |
| 0:15 – 0:45 | [M1 – API Essentials & Live Demo](modules/01-api-fundamentals.md) | An API is a *waiter* between apps; HTTP verbs, JSON, status codes & Swagger UI | Talk + interactive browser demo |
| 0:45 – 1:15 | [M2 – Introduction to DevSecOps](modules/02-introduction-to-devsecops.md) | Shift Left: automating SAST, SCA, and secret scanning into the assembly line | Discussion + GitHub Actions walkthrough |
| 1:15 – 1:30 | ☕ **Mid-Session Break** | Recharge & stretch | Refreshments |
| 1:30 – 2:15 | [M3 – API Security Deep Dive](modules/03-api-security.md) | OWASP Top 10, BOLA, mass assignment, constant-time auth & rate limiting | Live attack demos & code defense |
| 2:15 – 3:00 | [M4 – Cloud Integration](modules/04-cloud-integration.md) | Modern Cloud Native: API Gateways, IAM, Secrets Manager, Containers & Observability | Architecture walkthrough + checklist |
